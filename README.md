# Python Assignment 3 – While Loop, For Loop and Functions

## 📌 About the Assignment

This assignment focuses on Python loops, control statements, and functions.

The objective is to understand how to use while loops, for loops, and functions to solve basic programming problems.

## 🎯 Topics Covered

### 1. While Loop – Number Guessing Game

- Generate a random number between 1 and 10 using the `random` module.
- Allow the user to guess the number with a maximum of three valid attempts.
- Use a `while` loop to repeat the guessing process.
- Use `if`, `elif`, and `else` statements to check the guess.
- Use `continue` to skip invalid guesses.
- Use `break` to stop the loop when the correct number is guessed.
- Use the `while-else` statement to display a message when the attempts are over.

### 2. For Loop – Multiplication Table Generator

- Accept a number from the user.
- Use a `for` loop to generate the multiplication table.
- Use the `range()` function to iterate from 1 to 10.
- Calculate and display the multiplication results.

### 3. Functions – BMI Calculator

- Define a function named `calculate_bmi(weight, height)`.
- Accept the user's weight in kilograms.
- Accept the user's height in meters.
- Calculate BMI using the formula:

  BMI = Weight / (Height × Height)

- Return the calculated BMI using the `return` statement.
- Display the BMI rounded to two decimal places.
